Setup Tutorial
🔻 Step 1: Disable Core Isolation (Memory Integrity)
Press Start, type Core Isolation, and open it.
Click Core isolation details.
Toggle Memory integrity to Off.
Restart your PC.

🔻 Step 2: Disable Virtual Machine Platform (Optional)
Press Start, search Windows Features, and open it.
Uncheck Virtual Machine Platform.
Click OK, then restart.

🔻 Step 3: Disable Real-Time Protection
Go to Windows Security → Virus & threat protection.
Click Manage settings under "Virus & threat protection settings".
Turn Real-time protection to Off.

🔻 Step 4: Disable Windows Firewall
Go to Windows Security → Firewall & network protection.
Click each network (Domain, Private, Public).
Turn Firewall off for each.

🔻 Step 5: Disable Reputation-Based Protection
Go to Windows Security → App & browser control.
Click Reputation-based protection settings.
Turn everything OFF.

🔻 Step 6: Disable Secure Boot
Restart your PC and enter BIOS (usually Del, Esc, or F2).
Find Secure Boot and set it to Disabled.
Save and exit BIOS.
